# FGA 한국어판: 그로텐디크의 『대수기하학의 기초』(Fondements de la géométrie algébrique)

알렉상드르 그로텐디크(Alexandre Grothendieck)의 『대수기하학의 기초』(*Fondements de la géométrie algébrique*,
FGA)의 한국어 완역입니다. 1957–1962년 부르바키 세미나(Séminaire Bourbaki) 강연 149, 182, 190, 195, 212, 221, 232,
236과 각 강연의 정오표 및 보충, 1962년 논평을 한 권에 담았습니다.

## 만든 방법

한국어 번역, 교정, 편집, 조판은 AI가 했습니다. 번역의 기준은 프랑스어 원문([fga-fr](https://github.com/KokunoYumeto/fga-fr)의
교정판)이며, 영어판([fga-en](https://github.com/KokunoYumeto/fga-en))은 의미가 모호한 곳을 확인하는 데에만
썼습니다. 용어 선택의 근거는 [evidence/review](evidence/review/FGA_COMPLETE_EXPERT_REVIEW_20260908.md)의 기록에
있습니다. 원문의 쪽 번호는 여백에 표시했습니다.

## 상태

완역입니다. 오류가 남아 있을 수 있습니다.
