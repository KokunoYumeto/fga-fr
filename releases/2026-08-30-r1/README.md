# FGA French canon correction release candidate

This bounded package contains the complete maintained French FGA reader after admission of FGA-CANON-ERR-0001 through FGA-CANON-ERR-0017, together with editable sources and exact provenance/QA evidence.

The frozen printed French authority witnesses were not altered. Corrections are explicit in the maintained edition and are annotated by stable canon IDs. This package is publication-ready but has not been uploaded because no existing language-specific FGA GitHub repository or Zenodo concept could be proved from the maintained publication controls or anonymous public identity checks.

Historical combined FGA concept: 10.5281/zenodo.21792434. It is not used as the destination for this package because its current public head combines multiple languages.
